## 重复检查

运行 scripts/check.ps1。可选 MySQL 测试需要另建完全空白、名称以 depeg_import_test_ 开头的数据库，在进程环境中设置 DEPEG_MYSQL_TEST_DSN，再运行：

```powershell
go test -buildvcs=false ./internal/adapter/persistence/mysql -run TestMySQLMigrationResumeAndImport -count=1
```

该测试会创建表并写入测试数据，第二次运行应使用另一个空白库；不符合前缀的数据库会被拒绝。业务库按 [导入说明](import-coingecko.md) 显式迁移和导入。

小时包全量已校验，真实小时写入采用 a7a5 样本；没有将 123 万条小时数据全部写入业务库。当前没有前端、自动采集、Redis、模型推理或生产部署验证。
