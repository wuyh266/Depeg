# 市场总览中的多资产趋势对比

在「市场总览 → 稳定币市场」面板右上方增加「资产列表 / 趋势」切换。趋势与资产表位于同一面板，原有币种详情、规则和检测入口继续使用。

## 使用方式

1. 重启 Go API，然后在浏览器强制刷新页面。
2. 登录，进入市场总览，点击稳定币市场面板右上角的「趋势」。
3. 默认展示当前数据口径下按市值优先排列的三个资产，默认区间为已导入数据末尾的 30 天。
4. 勾选需要的资产，最多同时对比 8 个。不同资产采用不同颜色，取消其中一个资产不会改变其余资产的颜色。
5. 选择日期或使用 7 天、30 天、90 天、1 年、全部等快捷范围；OHLC 受现有接口限制，仅提供 7 天和 30 天快捷范围，单次最多 31 天。
6. 「价格」显示同币种报价的历史价格；「区间涨跌幅」使用各资产在所选区间内第一条有效价格为基点。各资产实际首末记录日期会显示在卡片中。
7. 悬停、触摸图表，或聚焦图表后使用左右方向键，查看同一时刻的读数。无对应观测的资产显示「—」。下方资产卡片可以进入币种详情。

## 数据与实现取舍

- 继续使用现有受 JWT 保护的 dashboard、market-snapshots 和 trends API，前端不连接外部数据源。
- 仅对相同类型、数据来源、采样周期、报价货币的行情叠加；通过「数据口径」下拉框切换不同组，避免将日快照和 OHLC 拼接。
- 明确按 UTC 日期查询；默认日期随数据时间变化，历史数据不会因为当前日期变化而默认查空。
- 同一时间只加载两个资产，完整读取每个资产的游标分页后再绘图；每个资产最多读取 12,000 条，超过时明确提示缩小范围，不显示被截断的曲线。
- 对较长曲线保留分段极值以减少 SVG 节点；缺失时间和空值处断线，原始读数不插值。
- 源十进制字符串保留在查询结果中；JavaScript 数值转换只用于绘图和展示涨跌幅，正式检测仍由现有后端执行。
- 某个资产读取失败时显示其错误及重试入口，已成功的资产仍可展示；全失败时清空旧图，避免旧数据被误认为本次查询结果。
- 退出趋势页、切换来源、重新提交范围或退出登录时取消旧请求并释放图表尺寸观察器，防止过期响应覆盖新视图。
- 复用原有 SVG 实现，不新增运行时图表依赖。新视图的样式随 Go 静态资源一起嵌入，因此更新后需要重新启动 API。

## 验证

图表计算验证：

```powershell
node --test web/charts.test.mjs
```

Go 检查：

```powershell
go test -buildvcs=false ./...
```

另在独立临时数据库中导入实际 CoinGecko 日行情，使用浏览器验证多曲线颜色、悬停和键盘读数、日期范围、完整分页、币种选择、空区间、非法日期、部分失败、离线重试、手机布局及原有详情与退出流程。

手动复核可选择 USDT、USDC、DAI，将日期设为 2023-03-09 至 2023-03-15，比较这段实际历史记录的价格变化。
