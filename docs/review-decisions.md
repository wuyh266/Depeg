## 本次导入适配的新增取舍

- 使用 Go 原生 parquet-go v0.32.0，新增解析依赖；不增加 Python 运行时要求。
- 每日市场快照与 K 线分别存储，新闻按原始元数据独立存储。新闻展示接口留到后续。
- 缺失成交量和未知锚定价格使用 NULL；不同 coin_id 不凭简称合并。
- 来源已有二进制浮点精度限制。规范列舍入到 18 位小数，同时保存最短可往返原值文本、标记舍入，避免无记录地改变数据。
- 单包事务保持一致性，代价是大包导入期间事务较长；当前不加入断点恢复、后台任务或 Redis。
- 新增显式前向迁移，避免自动删除新表或把缺失成交量强行改为 0 来恢复 NOT NULL。
